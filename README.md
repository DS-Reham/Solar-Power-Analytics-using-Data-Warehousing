# Solar-Power-Analytics-using-Data-Warehousing
Solar power data warehouse &amp; ETL pipeline using Star Schema, OLAP analysis, and Python to combine solar radiation, weather, and power data

Renewable energy systems generate large volumes of data from multiple sources, making it challenging to integrate, organize, and analyze information efficiently. In this team project, we built a centralized data warehouse to support data-driven decision-making for solar power generation.

We integrated three heterogeneous datasets containing solar radiation, weather sensor, and power generation data. The project involved data profiling, preprocessing, schema matching, ETL pipeline development, Star Schema design, OLAP analysis, and dashboard creation. We also resolved semantic conflicts between datasets and transformed raw data into a well-structured analytical model.  

The resulting data warehouse enabled meaningful insights into solar energy production, including identifying peak generation hours, evaluating inverter performance, analyzing the relationship between solar irradiation and power generation, and supporting future business intelligence and predictive analytics initiatives.

Technologies & Tools: Python, Pandas, SQL, Google Colab, Kaggle, ETL, Data Warehousing, Star Schema, OLAP, Business Intelligence.
